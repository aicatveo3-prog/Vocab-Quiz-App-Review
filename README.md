# 영단어 앱 리뷰 모음 (review-site)

국내·해외 영단어 앱 83개의 구글 플레이 리뷰를 앱별로 모아, 칭찬과 불만을 따로 볼 수 있는 정적 사이트.
(Ver2 학습 앱과는 별개이며, Ver2 파일은 건드리지 않는다.)

## 열기
- `index.html` 을 **더블클릭**하면 된다 (서버 필요 없음).
- 다른 기기에서 보려면 폴더째 서버에 올리면 되지만, 지금은 어디에도 올리지 않았다.
- 주의: Ver2 앱 폴더(상위)를 서버 루트로 띄우면 Ver2의 서비스워커가 이 폴더 파일을 캐시해서 수정이 안 보일 수 있다. 이 폴더를 루트로 띄우거나 더블클릭으로 열 것.

## 구성
- 홈: 사람들이 좋아하는 것/싫어하는 것 요약 + 국내 앱 51개 / 해외 앱 32개 목록(다운로드 많은 순, 앱 이름·주제 검색).
- 앱 상세: 불만(1~2점) / 칭찬(4~5점) / 보통(3점) / 전체 탭, 주제 막대(누르면 그 주제만), 주제 칩, 리뷰 안 검색, 정렬(공감·최신·별점).
- 해외 앱 중 한국어 리뷰가 적은 앱은 영어 리뷰가 기본으로 열리고, 위의 언어 탭으로 바꿀 수 있다.

## AI 요약 (말해보카, 저절로암기 영단어, 해커스보카, 해커스공무원 기출보카, 공무원시험 영어기출, 진가영 공무원 영어앱)
- 앱 상세 화면 맨 위에 "AI가 리뷰를 읽고 정리한 요약"이 있다: 한 줄 평가 → 불만/칭찬 "구체적인 주장" 카드(건수·최근 12개월 건수·연도별 분포·대표 리뷰·근거 리뷰 펼치기) → 건의 모음 → 시험 준비자 의견 → 확인 가능한 사실(가격·정책) → 시간 흐름 → 우리 앱 시사점.
- 요약이 있는 앱은 부정확한 키워드 막대를 숨기고, 홈 카드에도 요약의 1위 주장을 보여준다. 지금은 **말해보카**, **저절로암기 영단어**, **해커스보카**, **해커스공무원 기출보카**, **공무원시험 영어기출(어휘·문법)**, **진가영 공무원 영어앱** 6개가 있다. 진가영 앱은 후기가 18개뿐이라 직접 써 본 비중이 크다(로그인 뒤 학습 화면까지, 19건 비교).
- 만드는 법: 수집한 리뷰를 AI가 전부 읽고 같은 말끼리 묶어 `tools/summary/<앱id>.json` 에 주장·설명·리뷰 번호(idx)를 적는다. `build_site.py` 가 건수·최근 건수·연도 분포를 계산해 `data/summary/<앱id>.js` 로 내보낸다. 리뷰를 다시 수집해 순서가 바뀌면 `sourceFirst` 검사에서 빌드가 멈춘다(번호가 낡았다는 뜻).
- 건수는 AI가 직접 분류한 것이라 한두 건 오차가 있을 수 있고, 표본(앱당 약 340개) 안에서의 건수다.

## 조사 예정 후보 앱
- 홈의 네 번째 탭 "조사 예정"(`data/candidates.js`, 화면은 `js/app.js`의 `candCard`). 아직 리뷰를 수집하지 않은 공무원 영어 후보 12개(어휘 앱 6·기출 문제풀이 앱 6)를 다운로드 많은 순으로 보여 준다. 카드를 누르면 구글 플레이 페이지가 새 창으로 열린다. 다운로드·평점·업데이트 날짜는 2026-10-20 플레이스토어 표시값이다.
- 후보: 오르조, 에듀윌 합격앱, 9급 공무원 시험 기출문제(Trutory), 런투런 학습앱, 영단어는관리다, 틈틈영어-9급, 틈틈봇-공무원시험대비, 공풀, 합격왕, 필수 영단어 카드(간큰토끼), 외워보카, 재미로 영어. 조사를 마치면 `data/candidates.js`에서 지우고 `build_site.py`로 `data/apps.js`에 넣는다.

## 우리 앱과 비교 (가져올 점·피할 점)
- 홈 맨 위의 링크(`#/compare`)로 열리는 한 페이지. 6개 앱(해커스공무원 기출보카·공무원시험 영어기출·진가영 공무원 영어앱·말해보카·저절로암기·해커스보카)을 우리 앱(Ver2)과 견줘 "가져올 점 10개(크기 작음/중간/큼) · 피할 점 12개 · 지킬 점 · 제안 순서 · 정해 주실 것 4가지"로 정리했다. 표에는 '듣기' 줄을 새로 넣었고, 진가영 앱에서 나온 근거(후기 3개 글이 자동 넘김·재생 속도 조절 요청, 끝 화면의 '다시보기 단어만 공부' 갈래, 로그인 장벽, 점수·오답 목록 없음, 권한 안내 반복, 판 따로 두기)를 듣기 모드·3단계 훑어보기·피할 점·지킬 점에 보탰다. 2026-10-20에 영어기출을 추가하면서 우리 앱 코드를 다시 확인해, 이어 풀기·틀린 것 다시 풀기가 이미 있다는 점과 앱을 열 때마다 시험 선택 화면이 뜬다는 점(처음엔 '없다'고 잘못 적음)을 고쳤다.
- 글은 `data/compare.js` 에 있고, 그리는 코드는 `js/app.js` 의 `renderCompare`. 우리 앱 쪽 내용은 Ver2 코드·README 로 확인한 것이고, 다른 앱 쪽은 이 사이트의 요약과 직접 써 본 결과다. 우리 앱 사용자 반응은 아직 없어서 제안일 뿐이며 Ver2 코드는 바꾸지 않았다.

## 직접 써 본 결과 (말해보카, 저절로암기 영단어, 해커스보카, 해커스공무원 기출보카, 공무원시험 영어기출, 진가영 공무원 영어앱)
- 요약 화면의 "직접 써 봤더니" 섹션: 에뮬레이터(LDPlayer, 안드로이드 9)에서 앱을 무료 상태로 써 보고, 리뷰의 주장이 맞는지 "리뷰와 같음 / 리뷰와 다름 / 일부만 확인"으로 표시했다. 화면 캡처는 눌러서 크게 볼 수 있다(말해보카 25장 `img/mh/`, 저절로암기 33장 `img/wf/`, 해커스보카 12장 `img/hv/`, 해커스공무원 기출보카 33장 `img/gs/`, 공무원시험 영어기출 51장 `img/pb/`, 진가영 공무원 영어앱 52장 `img/jk/`).
- 요약 맨 위의 "앱 소개 보고서"(`overview`)는 앱이 어떤 방식인지(흐름·화면·무료/유료·우리 앱과 비교)를 화면 캡처와 함께 적은 것이다.
- 데이터는 `tools/summary/<앱id>.json` 의 `handsOn`(findings·shots) 과 `overview` 에 있다. 캡처는 540px JPEG로 줄였고, 개인정보(이메일·이름)가 보이는 화면은 쓰지 않았다.
- 저절로암기는 잠금화면 앱이라 에뮬레이터를 세로 폰 화면(1080×1920)으로 바꿔 확인했고(끝난 뒤 원래대로 복구), 사용자 허락을 받아 약관 동의와 '다른 앱 위에 표시'·위치 권한을 이 앱에만 주었다(끝난 뒤 회수). 결제 버튼과 광고는 누르지 않았다.
- 해커스보카는 교재 구매 인증이 필요한 퀴즈 앱이고, 학습 콘텐츠 내려받기가 두 번 모두 멈춰서(안드로이드 9 에뮬레이터) 퀴즈 화면에는 들어가지 못했다. 홈·내려받기·빈 단어장 안내·설정까지만 확인했고, 그 한계를 화면과 보고서에 적어 두었다. 앱 안의 권한은 하나도 허용하지 않았다.
- 해커스공무원 기출보카는 로그인·인증코드 없이 Day 10까지 열려서 단어 목록·카드·복습게임(예문 빈칸)·검색·설정까지 직접 봤다. Day 11부터는 인증코드(+로그인) 창이 떠서 거기까지만 확인하고 코드·로그인은 입력하지 않았다. 리뷰의 '등록 후 30일'은 확인하지 못했고, 소리·가로 보기·한국어 뜻 검색 등 못 본 것은 화면에 적어 두었다. 광고성 정보 수신은 첫 창에서 '거부'를 눌렀고 앱설정에서도 꺼져 있었다.
- 공무원시험 영어기출(어휘·문법)은 가입·로그인 없이 전체가 열려서 시험 3개(2026·2025 국가직, 2024 지방직)와 랜덤 풀기, OX/구문독해, 단어장(VOCA)·단어 퀴즈·검색, 주요 키워드, 체크노트, 설정·구독 화면까지 직접 봤다. 구독 결제와 광고 시청은 하지 않았고, 압박타이머가 도는 화면·소리·한국어 검색·오프라인은 확인하지 못해 화면에 적어 두었다. 오프라인을 보려고 에뮬레이터의 Wi-Fi를 끄면 에뮬레이터가 멈춰서(adb 응답 없음) 재시작해야 했다 — 다음에는 Wi-Fi를 끄지 말 것. 설정 화면 아래쪽 캡처에 개발자 이메일이 보여서 `img/pb/set2.jpg`에서 그 줄을 가렸다.
- 진가영 공무원 영어앱(`com.eduspa.voca.prof23`, 버전 AP-1.0.71)은 학습 기능이 모두 박문각 로그인 뒤라, 로그인 전에는 코스 선택·권한 안내(앱이 요청하는 권한이 없는데 '모두 허용' 안내가 홈에 돌아올 때마다 뜸)·교수소개·로그인 화면까지만 봤고, 이후 **사용자가 에뮬레이터에서 직접 로그인**한 뒤 폰 비율(`wm size 1080x1920`)로 2024·2025 코스의 일차 목록, STUDY, TEST, 나의 단어장, 전체 듣기(알림창·화면 끄기·백그라운드), 설정·코스 바꾸기를 모두 봤다(캡처 52장 `img/jk/`, 로그인 전 8장은 가로 960×540·로그인 뒤는 세로 540×960). 계정 정보는 보거나 입력하지 않았다. 에뮬레이터 소리는 들을 수 없어서 발음·'소리가 안 난다'는 확인하지 못했고, 설정의 '업데이트'·'진도율 초기화'(지울 수 있어서)와 다른 기기 연동은 누르지 않았다. 시험하다 같은 계정에 진도가 남았고(2024 DAY 1 학습완료, 2025 DAY 1 암기 50개, DAY 15·27 일부 열람, 북마크 3개), 설정의 반복 횟수 슬라이더를 바꿨다가 원래 값(단어 3·뜻 1)으로 되돌렸다. 스토어 소개 이미지는 개발사 홍보물이라 사이트에 넣지 않았다.
- 확인하지 못한 것(말해보카: 음성 인식·며칠에 걸친 복습·푸시·리그, 저절로암기: 배터리·데이터·소리·전화 수신·주머니 오작동 등)은 각 화면에 따로 적어 두었다.
- 다른 회사 앱의 화면 캡처이므로, 문제 제기가 있으면 캡처를 내린다.

## 데이터
- 수집일: 2026-10-18. 앱마다 별점 1~5점별로 "공감 많은 순" 일부(1점 100 · 2점 50 · 3점 30 · 4점 60 · 5점 100개까지)만 모은 **표본**이다. 1점을 많이 모아서 불만 비율이 실제보다 커 보일 수 있다.
- 작성자 이름·사진·개발사 답글은 저장하지 않았다.
- 주제 분류(결제·광고·오류 등)는 키워드로 자동 계산한 것이라 정확하지 않다.
- 앱 목록은 "영단어" 관련 검색어로 모은 것이라 빠진 앱이 있을 수 있다. 국내/해외 구분은 개발사 이름 + 추정(?)이다.
- 리뷰가 없는 앱(헤이워드 영단어, 토익 어휘(iBean) 등)은 상세 화면에 "수집된 리뷰가 없어요"로 나온다.

## 다시 만들기
`tools/` 에 수집·변환 스크립트와 원본(`raw/`, `raw_en/`)이 있다.
```
cd tools
python collect.py        # 한국어 리뷰 수집 → raw/   (이미 있는 앱은 건너뜀. 새로 받으려면 raw/ 를 지울 것)
python collect_en.py     # 한국어 리뷰가 적은 해외 앱의 영어 리뷰 → raw_en/
python build_site.py ..  # raw → data/apps.js, data/r/*.js
```
앱을 추가/삭제하려면 `tools/apps_meta.py` 의 KR / EN 목록을 고친다.

## 파일
- `index.html`, `css/style.css`, `js/app.js`
- `data/apps.js` 앱 목록·통계, `data/r/<앱id>.js` 한국어 리뷰, `data/r/<앱id>.en.js` 영어 리뷰, `data/summary/<앱id>.js` AI 요약

## 출처와 저작권
- 리뷰 본문은 구글 플레이 스토어에 공개된 한국어·영어 리뷰이며, 개인 연구(영단어 앱 비교)를 위해 일부만 인용했다. 작성자 이름·사진은 싣지 않았다.
- `img/mh/`(말해보카), `img/wf/`(저절로암기 영단어), `img/hv/`(해커스보카), `img/gs/`(해커스공무원 기출보카), `img/pb/`(공무원시험 영어기출), `img/jk/`(진가영 공무원 영어앱) 의 화면 캡처는 해당 앱을 직접 써 보며 찍은 것이다. 각 앱의 이름·화면에 대한 권리는 해당 회사에 있다.
- 삭제를 원하면 이슈로 알려 주세요.
